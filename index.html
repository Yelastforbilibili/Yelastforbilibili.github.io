ProtoBot

Python 3.12+ · asyncio · MIT

A Minecraft protocol client written straight onto TCP sockets: handshake through play, a deterministic 20 Hz physics engine, A* navigation over the server’s exact collision shapes, and a goal layer that refuses to call a job done until the server’s own world agrees. Seven releases, one code path.

Kelire

Windows · Python 3.10+ · PySide6

A desktop downloader for anime with a local HLS proxy bolted to its chest: 24 concurrent segments, disk-backed prefetch, seek priority that jumps the queue, and per-episode preloading — so a site that rate-limits one connection behaves like a normal video player.

  • 24concurrent segments
  • ~1sseek to 92% and back
  • 2themes, ZH / EN live switch

About

One person, one repo at a time

“The interesting bug is always on the other side of the wire.”

I write the half of a system that can be checked. Protocol clients, local proxies, caches with a cursor — code whose whole job is to turn “it probably worked” into something you can assert.

Most of what I build runs on one machine and talks to itself: a Paper server on loopback, a proxy on 127.0.0.1, a UI that never leaves the desktop. Small surfaces, honest logs, no account, no cloud, no telemetry.
